# Josh Kim Web Portfolio

A modern portfolio website built to present Joshua Kim’s projects, technical skills, and professional background in a clean and interactive way.

This project also includes an AI-powered portfolio assistant that helps visitors learn more about my work, experience, and development approach through natural conversation.

## Overview

This portfolio was designed not only as a personal website, but as a practical project to demonstrate frontend development skills, component-based architecture, and AI feature integration.

It focuses on:

- Clear presentation of projects and experience
- Responsive and modern UI design
- Maintainable content structure using JSON-based data
- Integration of an OpenAI-powered assistant for a more interactive user experience

## Tech Stack

- **Next.js (App Router)** – for modern React-based routing and page structure
- **TypeScript** – for safer and more maintainable code
- **Tailwind CSS** – for rapid and consistent UI styling
- **Vercel** – for deployment and hosting

## Key Features

- Responsive portfolio homepage
- Dedicated pages for projects, experience, and contact information
- Floating AI assistant launcher
- Dedicated AI assistant page
- JSON-based content management for easy updates
- OpenAI-powered chat assistant integration

## Why I Built This

I wanted to create a portfolio that goes beyond a static personal website.

Instead of only listing projects and skills, I aimed to build a more interactive experience where visitors can directly ask questions about my background, technical experience, and projects through an AI assistant.

This project also gave me practical experience in structuring a scalable Next.js application and integrating AI into a real user-facing product.

## Project Structure

- `app/` – application routes and pages
- `components/` – reusable UI components
- `data/` – JSON files storing portfolio content
- `public/` – static assets
- `api/` – API routes for AI assistant functionality
